# ISS Live Orbit Tracker & Simulator

[English version is here](README.md)

国際宇宙ステーション（ISS）の現在位置を、黒基調のダークテーマ地図上でリアルタイムに追跡する単一ページのWebアプリです。昼夜の表現、軌道の描画、日時を指定したシミュレーション機能を備えています。

## 主な機能

- **複数衛星 & スペースデブリ群のリアルタイム追跡・軌道表示** — デフォルトの国際宇宙ステーション（ISS）に加え、以下の科学衛星およびスペースデブリ群を地図上に表示・追跡できます：
  - **国際宇宙ステーション (ISS)** (NORAD ID: 25544)
  - **中国宇宙ステーション (天宮 / CSS)** (NORAD ID: 48274)
  - **ハッブル宇宙望遠鏡 (HST)** (NORAD ID: 20580) — 軌道上から深宇宙を観測し続ける宇宙望遠鏡
  - **Terra (EOS AM-1)** (NORAD ID: 25994) — NASA地球観測システム(EOS)の中核フラッグシップ衛星
  - **Landsat 8** (NORAD ID: 39084) — 高解像度陸域観測衛星
  - **Landsat 9** (NORAD ID: 49260) — Landsat 8と同一軌道面を8日位相差で追尾する最新姉妹衛星
  - **BlueWalker 3** (NORAD ID: 53807) — 巨大通信アンテナを備えた超高輝度衛星
  - **Envisat (環境観測衛星)** (NORAD ID: 27386) — 極軌道を周回する大型地球観測衛星
  - **SL-16 R/B (旧ソ連 Zenitロケット残骸 9機)** — 高度約840kmを周回する巨大デブリ群（NORAD ID: 19650, 25407, 23405, 24298, 20625, 22566, 23088, 23705, 31793）。1つのチェックボックスで全9機の軌道を一括表示可能。
- **衛星セレクター（個別表示切替 & グループ一括表示）**:
  - チェックボックスで各衛星やデブリ群の表示ON/OFFを個別に切り替え可能（SL-16 R/Bは全9機を一括で地図上に出現/非表示可能）。
  - 各行または地図上の各デブリマーカーをクリックすると、その個体（例: `#25407`）のテレメトリ（緯度・経度・高度・速度・TLE元期）をリアルタイム追跡し、地図センタリングの対象に設定。
- **軌道の描画** — 各衛星固有のカラーで、過去1時間分（実績・破線）と未来1時間分（予測・実線）の軌道を描画し、未来軌道上には +15分／+30分／+45分／+60分の時刻バッジを表示します。
- **地上可視領域 (Footprint)** — 衛星の高度に応じて地平線までの電波・見通し可視領域円を動的に計算・描画します。
- **昼夜表現（ターミネーターライン）** — 地球上のどの地域が現在昼／夜なのかを地図上に重ねて表示します。
- **日時移動シミュレーション** — 任意の日時を指定して、表示中の全衛星の位置・軌道を確認できます。「現在時刻に戻る」でリアルタイム表示に戻せます。
- **言語自動切り替え** — ブラウザの言語設定が日本語の場合は日本語UIを、それ以外の場合は英語UIを表示します。
- **レスポンシブデザイン**:
  - PC表示: 緯度を赤道（0°）に固定し、経度のみ追跡対象衛星に追従して地図をパンします。
  - スマートフォン表示: ダッシュボードパネルは初期状態で折りたたまれており、地図は追跡対象衛星の緯度・経度の両方を中心に追従します。
- **TLEデータ（軌道要素）の自動・手動更新 & キャッシュ機能**:
  - **定期自動更新ループ**: アプリを開いている間、30分ごとおよび非アクティブタブ復帰時にバックグラウンドで全衛星の最新TLEを自動取得・反映します。
  - **手動更新ボタン (🔄)**: 衛星セレクター横のボタンから、いつでも全衛星の最新TLEを手動で再取得できます（乱打防止の5秒クールダウン付き）。
  - **TLE元期 (Epoch) の表示**: 各衛星のTLEがいつ測定・計算されたデータなのかをHUDおよびマーカーのポップアップに表示します。ハッブル宇宙望遠鏡など頻繁に更新されるLEO衛星のデータ鮮度を一目で確認できます。
  - **LocalStorageキャッシュ永続化**: 取得した最新TLEデータをブラウザ内に安全に保存し、次回起動時や一時的なネットワーク障害時も前回の最新TLEから即座（0ms）に描画・起動します。
- **最新のTLEデータ取得** — [CelesTrak](https://celestrak.org/) から各衛星の最新軌道要素（TLE）を並行取得します。取得に失敗またはタイムアウトした場合は、各衛星の内蔵フォールバックデータまたはローカルキャッシュにより即座に動作します。

## 技術スタック

- [Leaflet.js](https://leafletjs.com/) — 地図描画
- [satellite.js](https://github.com/shashwatak/satellite-js) — SGP4軌道計算
- [leaflet.terminator](https://github.com/joergdietrich/Leaflet.Terminator) — 昼夜表現オーバーレイ
- [Esri World Dark Gray Canvas](https://www.esri.com/) — APIキー不要の無料ベースマップタイル
- Vanilla JavaScript（ビルド不要・フレームワーク不使用）

## ファイル構成

```
index.html    ページ構造・マークアップ
style.css     スタイル全般（ダークテーマ、レイアウト、レスポンシブ対応）
script.js     アプリロジック（地図・軌道計算・多言語対応・イベント処理）
config.js     任意・Git管理外: Googleタグマネージャ用のGTM_IDを設定
```

## 使い方

ライブのTLEデータをHTTPS経由で取得するため、`index.html` を `file://` で直接開くのではなく、ローカルのWebサーバー経由で配信してください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開いてください。

`config.js` は任意のファイルでGit管理対象外です。Googleタグマネージャによるアクセス解析を有効にしたい場合のみ、以下の内容で作成してください。

```js
const GTM_ID = "YOUR_GTM_ID";
```
